# 小红书五图与配文

先查看 [图库](reference-library.md) 中选定参考。用户最新参考优先；缺省使用暖白 `#F6F4EE`、炭黑 `#20251F`、草绿 `#658451`，必要时少量橙色提示，真实运动照片与清楚的大标题。力量主题可以深色，饮食与日常活动可明亮，一套保持一致。

恰好五张独立 3:4 竖图，推荐 1080×1440；安全边距约 7%，统一页码和文字层级。照片不证明标题里的效果，不冒充研究对象、新闻现场或自己的训练成果。

| 页 | 内容 |
| --- | --- |
| 1 | 一句有依据的变化或问题，必要条件不能全藏到后面 |
| 2 | 到底发生了什么：新消息或研究结论与出处 |
| 3 | 证据适用范围、被误解之处或关键条件 |
| 4 | 对不同读者的意义，避免给所有人同一训练处方 |
| 5 | 与证据一致的原则或选择清单，加具体讨论问题 |

每页一个重点，通常不超过三个要点。先定五页逐字文案，再生成，记录每张提示词、参考 ID、构图、文案和限制。用户只改某一张时保留其余已确认成品。

人物姿势与器械关系要合理；生成图只作概念视觉，不承担未经专业核验的动作教学。密集表格优先可编辑文字排版，位图生成和编辑使用 imagegen。

逐张检查错字、数字、kg/kcal/次数等单位、手脚关节、人物与器械接触点、裁切、脚注和 375px 宽度可读性。不捏造前后对比、疗效或用户评价，不以体型羞辱吸引点击。

配文默认 300—600 字：短标题、前两行讲价值、三到五段事实与适用范围、一项可执行原则、一个具体问题、约四到六个相关标签、必要来源。数字有依据，个人经历仅在用户提供时可写，不机械重复五页文字。
