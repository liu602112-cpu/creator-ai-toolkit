# 公众号内容与排版

仅起标题时读定稿，只提供推荐标题与最多三个备选。完整文章默认 1200—1800 字，随信息量调整，包含约 60—100 字摘要和可编辑 Markdown 正文。

用读者的真实问题引入，接着讲新消息、来源、证据到底说了什么、哪些人适用、可以怎么理解或行动，最后提供讨论问题与原文链接。公众号比小红书深入，不简单拼接五图文字，作者和账号署名不凭空添加。

参考 [图库](reference-library.md) 的公众号版式和共享照片；默认健身生活杂志风：暖白、墨绿、炭黑，宽松段距、短段落、清楚的章节标识，照片承担场景与节奏。按主题调整颜色，不机械复用 AI 版的科技蓝或雪山。

封面横图单独设计，正文主视觉另作处理，按当时平台上传裁切框适配。照片标注作者与来源，示意图不能冒充训练成果或新闻现场；商品照片不暗示本人体验或品牌背书。

完整交付含标题摘要、正文、独立封面、实际用图和 HTML 排版预览。研究信息卡需可读且有来源。需要长图时分段导出，保留文字备份，不在句子和表格中间断页。

用 375px 等真实移动宽度核验字号、表格溢出、图片遮字及长链接换行。平台可能清理样式，进入后台时必须再预览；本地 HTML 不代表公众号后台已排版或保存成功。
