# 健身热点内容工作流

中文沟通，交付有出处、适合普通读者的健身资讯与分平台成品。由 ai-hot-publisher 改编，独立保存健身素材，只执行用户本次要求的阶段。

## 范围与路由

- 用户说“对齐”：只讨论目标、受众和分歧，不修改文件、生成成品或发布。
- “最近健身热点”“昨天到今天”：读 [热点与证据](references/news.md)，输出固定编号简报。
- “用第几条做”：从本任务已展示列表锁定标题和原文链接，不刷新榜单后取同序号。先恢复上下文和项目记录，无法恢复才问。
- “做一套小红书和公众号”：核验选题，按 [小红书](references/xiaohongshu.md) 与 [公众号](references/wechat.md) 完成真实文件与 ZIP。
- 只要标题、配文或修改某张图：读取现有成品，只处理指定部分。
- “参考图库”“这些图存起来”：读 [图库](references/reference-library.md)，实际查看、分类、保存原图并更新可浏览索引。
- “直接发布”“存草稿”“每天推送”：读 [发布与定时](references/publishing.md)，按已有授权执行并核验结果。

## 制作与交付

先明确发生了什么、为什么与读者有关、证据支持到哪里，再写成稿。热度与健康证据分别核验，具体规则见热点与证据。历史照片、参考图文字和旧稿数字不能成为新事实。

按平台、题材、构图和信息量筛选图库候选，再实际看图，记录选中的 ID 和理由。用户未给参考时使用已归档照片和对应平台默认风格，不虚构用户认可。

输出到当前可写工作区的 `fitness-hot-content/YYYY-MM-DD/主题/`。完整包包含：

- `选题与来源.md`：时间窗口、固定编号、事实、热度依据、证据条件、原始链接、参考图 ID。
- `小红书/01.png` 至 `05.png`、`配文.md`、`配图提示词.json`。
- `公众号/标题与摘要.md`、`正文.md`、`排版预览.html`、独立封面及文章实际使用的配图。
- `交付状态.md` 与核对内容后的 ZIP。

逐张打开导出图，检查中文、数字、单位、动作表现、裁切和手机可读性。五张独立图才算五图完成；提示词与拼贴预览不能替代成图。只要简报时交付简报即可。

## 能力依赖

- 联网检索与可用浏览器负责找热点；读取失败说明来源和影响，继续其他来源，不编造榜单。
- 生成或编辑位图使用当前 imagegen 技能与工具；照片归档仅做逐字节复制和哈希校验。没有生成能力时完成可做的文字，明确缺少成图。
- 图库脚本仅依赖 Python 标准库，提供 add / list / verify / gallery；命令见图库文档。
- 公开发布、保存草稿和定时分别按用户请求操作；安装 Skill 不会自动建立定时任务或公开发文。

## Eagle 制图参考入口

制作图片时优先使用 [Eagle 参考图库](../../apps/eagle-reference-library/SKILL.md)，先同步并筛选 `<用户自己的Eagle图库>`，实际查看候选原图后再生成。按 [参考图库](references/reference-library.md) 的 Eagle 优先规则记录选择；用户当前明确指定的参考优先级最高。公众号成品默认交付一张完整长图。
