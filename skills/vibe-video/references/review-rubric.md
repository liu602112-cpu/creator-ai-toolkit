# vibe 制作与复刻的验收

以“通过 / 需修改 / 未检查 / 不适用”记录，不凭感觉报 95% 或 100%。总体状态不能掩盖关键项未检查。原片近似取样的时间不伪装为单帧精确。

## 创作是否成立

| 项目 | 可观察判据 | 不通过的迹象 |
| --- | --- | --- |
| 观众所得 | 一句话能对应一个被解释的关系或转折 | 只有主题、金句和漂亮镜头 |
| 段落推进 | 每段带来新事实/关系/后果 | 换时代和人物但任务相同 |
| 素材职责 | 关键判断有对应原件或明确示意 | 氛围图承担未经证实的事实 |
| 状态变化 | 能指出初态、操作、结果 | 无关粒子/光效替代解释 |
| 连续对象 | 过渡前、中、后能追踪同一主体/节点 | 跳位、身份切错、连线漂移 |
| 节奏 | 有识别/理解时间，强调有强弱差 | 刚出现即切走、所有元素都弹跳 |
| 字幕与标签 | 目标观看尺寸下可读，遮挡受控 | 双语小字太小、解释字压主体 |
| 首尾关系 | 若选择闭环，末镜新增含义 | 仅重复一张开头图片 |

每片按选用的 3–5 个成功因子，指出至少一处对应镜头；没有采用的因子不强行补齐。

## 忠实复刻的差异表

对每镜记录原片与当前版：
- 素材身份/版本：同源、同人替代、另构图替代、待取得。
- 时长、起止点、节点先后：以帧/毫秒记录可测差异；未逐帧核对写未测。
- 主体位置和尺度：记录偏移方向与程度，不单靠“很像”。
- 字体与文字：内容、换行、层级、字距、起落；未知字体写近似。
- 运动：相机轨迹、速度变化、主体/环境/解释图形分开看。
- 光色与叠层：峰值亮度位置、冷暖交接、重影持续。
- 音轨：声音来源、对白起点、强拍/音效点与结尾；必须实际试听。

挑转场前、中、后三个位置及重要节点复看，再在实时 Studio 连续播放。画面前进、相应媒体已载入且无错误，才算播放验证。截图不能替代动态预览。

## 增强版的比较

每个增强项写“原问题→实际改动→可观察改善→代价”。例如小屏英文不清：调整字号/行距后在目标尺寸看得清，代价是与原版比例略不同。高分辨率应来自更好的源素材/重建图形，不能仅放大 720p 就宣称新增细节。

准确性增强优先检查迷宫不穿墙、节点对应、齿轮轴心/啮合、器械接触、棋子落点与计数一致。与故事无关的更多特效不自动算提升。

## 技术与交付

- 查局部边界：第一帧、每次切点、最后一帧；防止整体提前、音轨错位、末尾留黑。
- 当前工程适用的类型/构建检查通过，再核对实际 Studio。仅改动处复查，已有可靠检查不反复全量运行。
- 保留当前版本标识与审片记录。用户批准旧版或只说继续工作不等于批准新版导出。
- 获最终导出批准后检查文件尺寸/帧率/时长、完整解码、色彩与声画同步；未批准时只交可编辑工程与当前 Studio。
- 封面、素材归档等按用户当前范围与项目约定处理，本 Skill 不自动扩大交付。
