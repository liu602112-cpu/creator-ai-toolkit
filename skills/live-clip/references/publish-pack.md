# 发布包：标题、封面文字、正文、标签

第 2 步「想开头」时和开头一起出，用户要求飞书同步时，在选定开头后写进其指定的「成品视频」表。范例：0922 切1～9（2026-10-03，源作者案例）。

## 写法

受众：读 `config.json` 的 `audience`。安装时 audience 留空；audience_example 是喂鱼的受众示例（25–40 岁、非技术背景、职场焦虑、想借 AI 转行 / 涨薪的普通人），面向这一示例受众时，文案回答他们心里那句「我这种人还有没有机会」。学员的受众不一样时，按学员的受众换掉下表例子里的身份标签和标签词，公式不变。

| 项 | 规则 | 例子（0922） |
|---|---|---|
| 标题 | **身份标签 + 反差 + 具体数字**。不用术语（FDE、蒸馏、千川、渲染、语料、投放素材），不用从业者视角，不写功能说明 | 做了七八年UI被裁，转行后反而拿到20K／底薪15K签对赌，2个月没爆款直接走人 |
| 封面文字 | 两行：主字（≤10 字，判断句或数字对比）+ 副字（补身份或反差）。主字不和标题重复 | 设计师赶紧转 / 被裁后转行 20K；0 × AI = 0 / 没业务，AI用不起来 |
| 正文 | 3–5 句口语，把切片里最硬的事实（数字、身份、例子）复述一遍，结尾可以抛一个问题引评论。去 AI 味：不用「首先/其次」「赋能」「不仅…更…」 | 「这期两个学员都是设计师……你是做设计的吗？想往哪转，评论区聊聊。」 |
| 标签 | 4–5 个，单独写进「标签」字段，空格分隔，正文里不再重复。大众搜索词优先（#AI转行 #职场转型），行业词最多一个（#FDE 这类要提醒用户受众未必搜） | #设计师转行 #UI设计师 #职场转型 #AI转行 #商业思维 |

- 标题、封面要和选定的开头互相配合：开头是口播第一句，封面主字是屏幕大字，标题是刷到前看到的那行，三者说同一件事但不重复同一句话。
- 不确定写法的人名、机构名、账号名（比如识别出的「且曼学院」「旧梦留声机」）**不进文案**，列出来请用户确认。
- 行业内幕、薪资、客户名这类内容，用户没明确说能公开的，先问再写。

给用户看的格式：每条一个小节，列标题 / 封面（主／副）/ 正文 / 标签，最后单独列待确认项。

## 写进飞书

- 表：`config.json` 的 `feishu`（`base_token`、`table_id`、`view_id`）。用户给的是 wiki 链接时，先用 lark-wiki 换出 base token，再填回 config.json。先阅读当前安装的 lark-base Skill，按当前 CLI 帮助查看字段并确认字段名（用户会改名，比如「时长」改成「时长/s」）；缺字段就告诉用户，不要自己往用户的表里加字段。
- 需要 lark-cli 已登录（`lark-cli auth status`）。没装或没登录，先引导用户装好再写表；写不了表时，把发布包按字段整理成表格给用户，让用户自己粘贴。
- 写之前用 `+record-search` 按选题 / 逐字稿关键词查一下，同一条已有记录就更新，不新建。
- 字段对应：

| 时机 | 字段 | 内容 |
|---|---|---|
| 选定开头后（建记录） | 选题 | 切片名去掉「切N_」 |
| | 开头 | 选定的口播第一句 |
| | 标题、封面文字、正文、标签 | 发布包；封面文字写「主字\n副字」；标签写进「标签」字段（`#AI转行 #职场转型 …`，空格分隔），不再接在正文末尾 |
| | 直播回放日期 | `YYYY-MM-DD 00:00:00` |
| 精剪交付后（补） | 逐字稿 | `jy.py srt <草稿> --txt`，一句一行（以用户改过的版本为准） |
| | 时长/s | 整数秒 |
| | 本地路径 | 三行：`剪映源文件：<草稿目录>` / `时间线：<时间线名>（Timelines/<id>/draft_info.json）`（单条草稿就写 draft_info.json）/ `原片：<原片路径>` |
| 用户自己填 | 剪映预览链接、封面图、是否发布以下平台、是否通过 | 不动 |

- 批量创建和逐条更新使用当前 lark-base Skill 支持的命令。数据用 Python json.dumps 写入 UTF-8 JSON 文件，通过文件参数提交，不手拼 PowerShell JSON；引号由 JSON 序列化器转义。写入只在用户明确要求同步的范围内进行。
- 写完回读一次，确认在 `view_id` 那个视图里能看到。

## 没有表时

用户要求创建「成品视频」表时，用 lark-base 建表（建在学员自己的空间里），建完把 token 写进 `config.json`。字段：

| 字段 | 类型 |
|---|---|
| 选题 | 文本（主字段） |
| 开头 | 文本 |
| 标题 | 文本 |
| 封面文字 | 文本 |
| 正文 | 文本 |
| 标签 | 文本 |
| 逐字稿 | 文本 |
| 时长/s | 数字（整数） |
| 直播回放日期 | 日期 |
| 本地路径 | 文本 |
| 剪映预览链接 | 文本 |
| 封面 | 附件 |
| 是否发布以下平台 | 多选：视频号 / 抖音 / 小红书 / B站 |
| 是否通过 | 复选框 |
