# 怎么挑切片

## 值得切的段落
- **观点有冲突感**：反常识、下判断、给结论。比如「明年会死一大批账号」「公司只招两种人」「开头3秒直接抄」。
- **能单独看懂**：不依赖前文（「你刚刚说的那个」「像他这种」），不需要看到直播画面才能理解。
- **有结构**：三类、三个能力、两种岗位。结构越清楚，包装时越好做可视化（目录卡、链路）。
- **有具体例子或数字**：2万字文档月入6万、年包30万、200刀抵一个团队。
- **和账号定位一致**：AI×IP、AI视频、求职转行、内容方法论。

## 不要用的段落
- 课程价格、开课日期、招生名额：会过时，还有合规风险。
- 聊封号、钻平台漏洞、「道德感弱的AI」这类话题。
- 点名具体公司并且带负面评价的（「割韭菜」）。如果内容本身有价值，把公司名剪掉再用。
- 直播互动：扣1、进粉丝群、念ID、寒暄。
- 录制断档两边的内容（原片文件名时间明显不连续），接不上。

## 每条的结构
- **时长**：1–2.5 分钟。超过 2.5 分钟就拆成两条，或者只保留最硬的那段。
- **开头**：见下一节「开头怎么挑」。**每一条都要做**，不能直接用这段直播原来的第一句。
- **调换顺序**：可以用，比如「故事 → 讨论 → 金句收尾」。调完要检查指代：插在故事中间的「我之前也有这个疑惑」会让后面的「他」指代不明，这种直接删掉。
- **结尾**：落在结论或金句上，不要落在「然后」「所以」这种悬空的词上。
- **两条内容重叠**：同一段话可以同时出现在两条里（比如「策略岗」同时用在「三种能力」和「两种岗位」），前提是两条都能单独看懂。

## 开头怎么挑（第 2 步「想开头」用）
切片没法重写开头，开头是**从这段里选出来的**。直播的习惯是先铺垫，最狠的那句往往在中间或结尾，按原顺序剪，观众还没听到重点就划走了。所以重构一条时，先找开头，再排正文。
方法见 `references/hook/opening-package.md` 的「直播切片」一节、`references/hook/hook-patterns.md` 的式子。

**1. 找料**：通读这段，圈出最反常的结论、最具体的数字、最疼的一件事、最有画面感的例子。

**2. 每条出 2–3 个候选**，尽量用不同的式子：
| 式子 | 直播里长什么样 | 例 |
|---|---|---|
| 结果前置 | 把结论或后果搬到最前 | 「两个月之后做不出来爆款，你走人」 |
| 反差 | 「都以为 A，其实 B」，或前后对比 | 「23年AI画手还是六根手指，现在你再看手」 |
| 身份点名 | 第一句就点出受众是谁 | 「设计师只要不干设计，干什么都好干」 |
| 悬念 / 提问 | 抛出一个具体的问题，缺口要清楚 | 「未来什么样的人最值钱？」 |
| 损失 | 不这样做会亏什么 | 「你花自己的钱，连试错的成本都不够」 |

**3. 筛**，任何一项答「否」就换：
- **一听就懂**：不靠前文，没有指代不明的「他、这个」，没有观众不认识的术语（比如「FDE」开头，普通人听不懂）。
- **有具体的东西**：数字、身份、画面三样至少占一样。账号的高分规律是「身份标签 + 反差 + 具体数字」。
- **3–5 秒说完**，一口气的长度；可以从同一段里挑几个短句拼起来（ranges 分几段），不要整段搬。
- **正文能兑现**：开头许诺的东西，正文里一定要有，并且能指出在第几秒。
- **话要说全**：动词后面要有宾语，听的人能知道「做什么」。反例：「一个公司里面的销售，他都需要去做」（1001切8，用户反馈不吸引人）。
- **第一个字就是实词**：「嗯、就是、那个、然后」开头的都剪掉；尾音收干净再切。

**4. 接得上**：前置句后面跳回正文的第一句（承接句）要顺，最好是「这是什么 / 为什么」的问题或定义，比如「FDE是什么？」接在钩子后面就很合适。接不上的话，换一个钩子，或者把正文起点往后挪。

**5. 交付**：第 2 步单独出一张开头表，每条列推荐版和备选，每版标上源时间线的时间、式子、承接句、屏幕大字、为什么选它，让用户每条选一版。用户已经在剪映里改过的草稿，只给方案，不重新生成。

**6. 回填**：发布后有数据（2 秒跳出率、5 秒完播率），把开头原句、式子、数据追加到 `references/hook/hook-bank.md`「直播切片」一节。目前那一节还是空的，没有经过验证的数据，挑的时候靠判断，要如实告诉用户。
