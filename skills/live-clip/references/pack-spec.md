# 包装配置 pack.json

完整例子见 `example-0926/pack.json`（对应「靠AI视频找工作的三条路-可视化」）。

```json
{
 "source": "用户改过的草稿名",          // 只读，不会被改动
 "output": "新草稿名",                 // 不能和已有草稿重名
 "assets": "素材目录（相对 pack.json）", // 找不到的素材会再去 skill 的 assets/ 里找（vignette.png、scrim.png）
 "style_draft": "重点字",              // 从这个剪映草稿复制重点字样式和入场动画；本机没有这个草稿就用 presets/keyword_style.json
 "tail": 0.8,                          // 片尾延长几秒（原片后面是静音时用来给结论卡留时间）
 "camera": {"punch": 0.08, "push": 0.035},
 "vignette": true,
 "sections": ["短剧", "商单", "IP"],   // 章节条的标签
 "beats": [ ... ]
}
```

## 时间写法（at / to）
| 写法 | 含义 |
|---|---|
| `12.5` | 绝对秒数 |
| `"它会分为三个类型"` | 以这句开头的那条字幕的起点 |
| `"它会分为三个类型/三个"` | 这条字幕里「三个」开始说的时刻 |
| `"…+0.3"` `"…-0.25"` | 在上面的基础上加减秒数 |
| `"end"` | 片尾（`to` 省略时也是片尾） |

用「句/词」取时刻时，如果这句的逐字时间有错位，取到的时间会偏晚。**重点字统一从这句话开头出现**，词级时间只用来卡卡片和音效。

## beats 类型
| do | 做什么 | 主要参数 |
|---|---|---|
| `keyword` | 重点字：中文加英文装饰 | `zh` `en` `accent`（整组用重点色）`y`（默认 -0.33）`scale` `sfx`（默认「一次呼」，写 `""` 不加音效） |
| `menu` | 编号目录卡：01/02/03 逐行弹出 | `items` `highlight`（这几项亮成黄色）`dim`（这几项变暗）`ys` `scale` `sfx`(bool) |
| `cards` | 卡着台词逐个出现的标签 | `items:[{at, zh, prefix?, accent?, sfx?}]`；`arrows: true` 时条目之间加 ↓，做成链路 |
| `index` | 顶部章节条，当前章节黄色 | `active`（从 0 数） |
| `broll` | 全屏图片，带对焦转场 | `img` `enter` `leave`（出场 = 缩成卡片往上飘）`sfx` `sfx_out` |
| `caption` | 小字说明 | `text`（`\n` 换行）`y` `size` |
| `defocus` | 只做虚化，不加元素 | — |
| `sfx` | 单独加音效 | `name` `gain` |

任何 beat 加 `"defocus": true` 或 `[提前秒, 延后秒]`，就会在它出现期间让口播画面虚化并压暗。相邻 0.3 秒以内的虚化窗口会自动合并成一段，不会一闪一闪。

## 节奏
- 每 3–6 秒一个视觉事件（重点字、卡片或 B-roll）；前 5 秒至少两个。空档靠卡片和 B-roll 补，不要靠多塞重点字。
- **重点字一分半左右 8–10 个**，只给判断词、金句、数字；过渡词、复述不做。0926切1 第一版 98 秒放了 23 个，用户嫌多，删到 9 个（死一批 / 专业后期 / 绝对会死 / 流量不够分 / 一人成军 / 回归于人 / 活生生的人 / 直播加分 / 直接完蛋）。
- 重点字停留 1.4–3 秒。空跑时标了 ⚠ 的要调。
- 虚化段每段不超过约 15 秒；中间插一段清晰的口播，让人脸露出来。
- 结构类的话（「分为三类」）一定要做目录卡；结尾用同一套卡片回收，比如亮起推荐的那几项。

## 版面（剪映坐标：中心为 0，y 向上为正，画面上下边缘是 ±1）
| 元素 | 位置 |
|---|---|
| 字幕 | y = -0.56（用户的剪映默认位置） |
| 重点字 | y = -0.33，在下巴下方、字幕上方。4 个字时缩放 2.1，字越多等比缩小 |
| 英文装饰 | 中文右下角，x ≈ 中文半宽 × 0.8，y 比中文低 0.08 |
| 章节条 | y = 0.84 |
| 目录卡 | y = 0.34 / 0.10 / -0.14 |
| 近景口播 | 人脸在画面上方 60%，下方 40% 是衣服；浅色衣服上的白字要靠暗角托底 |

## 找素材
- **应用图标和截图**：用苹果应用商店的公开接口。本机 Python 的 SSL 证书有问题，要用 curl：
  ```bash
  curl -s "https://itunes.apple.com/search?term=<URL编码>&country=cn&entity=software&limit=2"
  ```
  - 图标取 `artworkUrl512`。
  - 截图取 `screenshotUrls`，要把地址最后一段换成 `1290x0w.png` 才是高清（默认只有 222×480）。
  - 海外应用用 `country=us`。
- **合成 B-roll**：用 PIL 合成 1080×1920 的图。
  - 竖屏截图：按 9:16 裁切后全屏。
  - 多个产品：深色底上放两张手机截图（圆角、投影、±5° 倾斜）。
- **提到的人和账号（博主、老师、公司号）：截他们的主页**，做成全屏 B-roll，卡在念到名字的那句上。0926切1 的范例：小Lin说、差评君各一张，结尾再提到时两张上下叠放回收。
  - 抖音网页有拖动拼图验证，自动化截不了，**不要尝试绕过**。按顺序选：用户给的截图或主页链接 → 用户连上 Chrome 扩展并登录抖音后截 → B 站主页（交付时说明用的是 B 站）。
  - B 站：`search.bilibili.com/upuser?keyword=<名字>` 找到 mid，用 Playwright（`channel="chrome"`，headless）截 `space.bilibili.com/<mid>`，视口 1280×1000、2 倍像素；截前把登录浮层隐藏。手机版 `m.bilibili.com/space/<mid>` 常弹点字验证，用桌面版。
  - 合成：裁头图 + 头像昵称 + 前两个代表作（2 倍图约 x 0–1300、y 0–1110），加 14px 直角白边和投影，放在画面 42% 高度；底图用同一张截图放大、高斯模糊、压暗到 35%。
  - 同名账号多、不确定是哪一个时（比如「泡泡老师」），问用户要链接，不要猜。
- 用户自己的照片（学员合照等）先问能不能用。
- 不要用动画人物之类有版权风险的形象；需要 IP 形象时用用户自己的。

## 输出草稿的图层（从下到上）
口播主轨 → 虚化副本（静音、挂「模糊」特效、透明度淡入淡出）→ B-roll → 压暗层 → 暗角 → 重点字 → 英文 → 卡片（多条轨道）→ 章节条 → 原字幕 → 音效（多条轨道）

## 已知风险
- 「模糊」特效（resource_id 7399495140399746304）的本地缓存可能已被清掉，剪映打开草稿时一般会按 id 重新下载。如果没下载，让用户手动加一次「模糊」特效。
- 我没法在剪映里看到实际画面，字号和位置都是按参考草稿估算的，交付时要说明。
