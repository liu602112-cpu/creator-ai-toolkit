# 开头包：四条轨、时间分层、形态差异

## 1. 四条轨

| 轨 | 观众接收顺序 | 它的活 | 常见事故 |
|---|---|---|---|
| **画面** | 最先，0.3 秒内 | 让他知道「这是什么类型的内容、有没有东西看」 | 第一帧是一张准备开口的脸；黑场；logo 片头 |
| **屏幕大字** | 第二，扫一眼 | 静音也能懂；给口播加一层信息 | 逐字重复口播；字太多；和标题一模一样 |
| **声音**（音效/BGM/人声的质感） | 和画面几乎同时 | 定情绪、给节奏 | 开头半秒空白；先吸一口气；BGM 盖过人声 |
| **口播** | 最后，要 1–2 秒才听完一句 | 钩子本身 | 写得好但前三条轨拖后腿 |

配合的原则是**互补不重复**：四条轨各说一点，合起来在 3 秒内把「钩子」拼完整。举例（测评类）：

- 画面：六张同题生成图一字排开，其中一张明显崩了
- 大字：「同一句提示词」
- 口播：「这六个模型里，最贵的那个画得最差。」
- 声音：第一个字落在画面切入的同一帧，无前奏

画面的三条经验：

- **已经在事情中间**。成品、对比、动作、出错的瞬间，优先于「人坐好了准备讲」。
- **一屏一件事**。第一帧信息太多等于没有信息。
- **人脸要么不出现，要么有表情有动作**。人脸天然吸引视线，但一张静止的无表情的脸传递的信息是「还没开始」。

## 2. 时间分层

开头不是「3 秒」，是三道关。

| 时段 | 观众在决定什么 | 靠什么过关 | 对应数据 |
|---|---|---|---|
| **0–1 秒** | 这是什么？划不划？ | 画面 + 大字 | 2 秒跳出率 |
| **1–3 秒** | 跟我有关吗？ | 口播钩子 | 2 秒跳出率、3 秒留存 |
| **3–8 秒** | 值得花时间吗？ | 承接句：留下来能拿到什么 | 5 秒完播率 |

之后每隔一段还要「再钩」一次（反转、具体数字、一声「更离谱的是」），那是中段的事，但开头要为第一次再钩留好位置：承接句结束的地方，最好就是第一件事开始的地方。

## 3. 承接句怎么写

钩子之后的第二句，是最容易漏人的地方。钩子把人刹住了，第二句开始「事情是这样的，我从 2019 年开始……」，5 秒完播直接掉。

承接句做两件事：

1. **交付预告**：告诉他留下来能拿到什么，最好带数（「三笔」「六个模型」「一张表」）。带数的预告自带进度条，给观众确定感。
2. **开环**：把最想知道的那个压到后面，并且明说（「最冤的那个我放最后」）。环开着，人走不掉。

写法：

- 钩子是悬念/损失 → 承接给路线：「这三笔我一笔一笔说，最冤的那个放最后。」
- 钩子是结果前置 → 承接倒回起点：「一周前我还不是这样。」然后立刻进第一件事，背景压到 5–10 秒以内。
- 钩子是提问代入 → 承接给一个最小答案，再升级：「其实只要改一个地方。——但改完你会发现第二个问题。」
- 钩子是反差/颠覆 → 承接给证据的预告：「我拿自己的 121 条开头数了一遍。」

不要在承接句里做的事：自我介绍、感谢关注、解释这期为什么做、把钩子换个说法再说一遍。

身份如果必须交代（新号、需要资格背书），放在承接句之后，用一句话带过，并且写成跟观众有关的信息：「我带过十一期学员，这个坑每期都有人踩」。

## 4. 标题、封面、第一句的分工

三者是同一个钩子的三个面，不要说同一句话。

- **封面**：给主页流量和搜索流量看的。要的是「一眼知道这期讲什么」，字少、主体大。
- **标题（文案区）**：放完整观点或关键词，服务搜索和转述。高赞账号的规律是「观点放标题，悬念放第一句」。
- **第一句**：给推荐流里正在刷的人，只管刹住。

检查：把标题、大字、口播第一句并排放，三句话如果是同义重复，砍掉两句重写，让它们各带一块不同的信息。

推荐流里封面基本不露出，首帧就是事实上的封面——所以首帧要按封面的标准设计，但不能是一张静态海报（静止 = 还没开始）。

## 5. 不同形态的开头

### 短口播（30–120 秒）
标准打法，就是 SKILL.md 的 A 流程。口播一句钩子 + 一句承接，8 秒内必须进入第一件事。

### 教程 / 工具实操
观众要先确认「学完能做出什么」。**先亮成品，再讲步骤**。

- 0–1 秒：成品画面，或「之前 / 之后」对比
- 口播：结果前置或提问代入（「这张图没用任何修图软件」「如果老板让你十分钟出一版，你会怎么做？」）
- 承接：一共几步、需要什么（「三步，全程只用一个工具」）
- 别在开头讲原理和软件介绍

### 测评 / 横评 / 排行
观众要的是结论和意外。**先亮最反直觉的那个结论，不亮完整排名**。

- 画面：所有选手同框，一眼看出差距
- 口播：规模开场或反差（「这六个模型我各跑了 40 遍，最贵的那个垫底」）
- 承接：评判标准一句话 + 开环（「第一名我之前都没听过，放最后说」）
- 排行类的顺序本身就是开环：从后往前揭晓

### 长视频（5 分钟以上）：冷开场
长视频的开头是 15–40 秒的一段，不是一句话。结构：

1. **冷开场**（0–10 秒）：全片最有劲的一个片段、一个结果或一个问题，直接切入，不加片头
2. **立题**（10–20 秒）：这期要回答的那个问题，一句话
3. **路线**（20–40 秒）：分几部分、看完能带走什么；这时候可以简短交代「我为什么有资格讲」
4. 再进正文，片头动画如果要有，放在这之后且不超过 3 秒

长视频观众对节奏的容忍度高一些，但前 30 秒的流失依然最大。别把短视频的「三秒钩完就开讲」直接搬过来——长视频更需要让人相信「后面这二十分钟值得」。路线预告在这里的价值比短视频大得多。

### 直播切片
切片没法重写开头，开头是**选出来的**。

- 入点选在一句完整的、带态度或带结果的话上，不要从「那我接着说」「对然后呢」开始
- 如果最狠的那句在这段的中间或后面，可以把它**前置成冷开场**（先放那句 2–4 秒，再跳回这段的起点），这是切片的「换顺序」
- 直播口语里的起手词（「嗯」「就是说」「那个」）在第一句里全部剪掉；尾音收干净再切，别为了快把字切掉半个
- 大字比口播更重要：直播画面单调，靠大字给出「这段在讲什么」；标题按「身份标签 + 反差 + 具体数字」
- 观众没有上下文，所以第一句里要有主语和对象，代词（「他」「这个」）要换回具体的名字

### 剧情 / 对话体
第一句从对话中间开始，第一句里就有冲突对象。不交代人物关系和背景，让观众从对话里自己拼出来。固定口号式开头长期看是减分项。

### vlog / 探访
第一镜是全片最有画面的那个地方或那个动作，口播晚半秒进，用新奇见闻式。别从「今天我要去……」的出发镜头开始。

## 6. 不同流量入口

| 入口 | 观众状态 | 开头侧重 |
|---|---|---|
| 推荐流 | 无目的地刷，随时划 | 刹车优先，首帧和第一句要强 |
| 搜索 | 带着问题来的 | 第一句直接确认「你搜的那个问题，这里有答案」，钩子强度可以低，清楚比刺激重要 |
| 主页 / 合集 / 粉丝 | 已经认识你 | 可以稍慢，可以用系列口吻，但仍然不要自我介绍 |
| 投流素材 | 被动看到，目标是转化 | 身份点名和损失优先，筛人比留人重要 |

## 7. 口播交付：嘴和剪辑上的事

写得好的钩子，会在录和剪的时候被毁掉。给出开头包时，把这几条一起提醒：

- **第一个字就是实词**。「那个……」「其实……」「嗯今天……」开口的，剪掉。
- **起音前零空白**。视频第一帧就该有声音，别留吸气和半秒静默。
- **第一句的能量比正文高半档**，语速稍快但字要清楚；钩子的最后一个词（反差的落点、数字）咬重，后面留一个很短的停顿让它落地。
- **第一句不换气**。写的时候就按一口气的长度写。
- **钩子说完别笑场、别垫话**（「对吧」「是不是」），直接进承接。
- 尾音收干净再切下一句，开头不是越赶越好——赶到听不清，等于没钩。
