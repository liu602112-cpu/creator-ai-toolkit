# 声音与数字人口播

使用获授权的配音与形象视频，组织音频驱动的数字人口播制作。

- 输入：指定配音、形象视频和输出要求
- 输出：视频制作任务、输入记录和成片检查

## 使用

把本目录复制到支持 Skill 的工具的技能目录，然后用自然语言描述任务。使用说明在 [SKILL.md](SKILL.md)。

## 公开版范围

保留方法、脚本与模板。私人 CSV、完整逐字稿、账号凭据、克隆声音、原始课程和第三方媒体不随包发布。示例数据用于演示，不代表真实传播效果。

需要用户自备飞影账号、获授权的音频与形象素材，并配置 HIFLY_API_TOKEN 或官方 MCP。运行生成会消耗服务积分；本次发布未调用付费生成。
