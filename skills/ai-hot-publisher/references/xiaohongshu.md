# 小红书五图与配文

先按 [参考图库](reference-library.md) 查看本次选定参考。用户新风格优先；没有更适合样式时用以下历史默认：白底、深宝蓝约 `#0734A4`、黑字、细灰线、大留白、细体中文标题、醒目数字、深蓝矩形与原创黑白撕纸插画。不复制参考账号、水印、署名或特定人物。

默认 3:4 竖图，推荐 1080×1440 或同等清晰度，安全边距约宽度 7%。五张统一标题层级、配色、边距、页脚及 `01 / 05` 至 `05 / 05` 页码。

| 页 | 职责 |
| --- | --- |
| 1 | 吸睛封面：一个有依据的数字、问题或新变化；主标题短，缩略图可读，保留关键条件 |
| 2 | 具体事实：发生了什么、对照数据或新功能 |
| 3 | 关键前提：机制、条件或被忽略的限制 |
| 4 | 读者影响：谁适合、有什么边界 |
| 5 | 实际行动：可保存清单、实践步骤或选择建议，附具体讨论问题 |

每页一个重点，通常三项以内。结构可随主题调整，不强迫所有选题做数字对比；不用无依据的“吊打”“全网第一”。

先写五页精确文字，再生成。每张提示词记录风格、页码、逐字文案、构图、来源与限定。位图生成和修改用可用 imagegen；已存在的 HTML/SVG 排版源文件可直接修源并重导出。只改一张时保留其他已确认图片。

逐张检查：中文错字、数字单位、比较对象、插画手部异常、脚注大小和裁切。异步生成须等完成并确认实际文件。最终是五张独立图片，不以拼贴预览充数。

## 配文

直接交付可复制成稿：简短标题（一般约 20 中文字符，实际以当前平台限制为准）、开头两行价值、三到五短段解释事实/前提/用法、一个具体讨论问题、约四到六个相关标签、必要来源说明。通常 300—600 字，按内容调整。

正文补充图片逻辑，不机械重复五页。不伪装亲身体验。用户只问配文时直接给配文，不默认重做图片。
