# AI 热点内容工作流

中文沟通，交付有出处、可直接使用的分平台成品。只执行用户当次要求的阶段。发现 AI 热点或执行每日推送时，必须实际调用已安装的 `aihot` Skill 和实时 API；具体规则见 [资讯与事实](references/news.md)。

## 范围与路由

- 用户说“对齐”：只讨论目标与分歧，不修改文件、生成成品或发布。
- “昨天到今天的热点”：阅读 [资讯与事实](references/news.md)，交付固定编号的简报。
- “用第六条做”：从当前任务实际展示过的列表找第六条，锁定标题与原文链接；不可重新抓榜后取新第六条。上下文与项目文件均无法恢复时再问用户。
- “生成公众号标题”“小红书配文是什么”：读取已有稿件，只交付所问文字；不重跑完整流程。
- 收到新参考图：阅读 [参考图库](references/reference-library.md)，先按平台存档。新增参考优先于历史默认样式。
- “做一套小红书和公众号”：完成事实核验、两平台文案、图像、排版及实际文件交付。
- “直接发布”：阅读 [发布与定时](references/publishing.md)，依据当前稿件与用户授权操作并核实结果。
- 保存工作流为 Skill 不等于创建新定时任务、每天制图或自动公开发布。

## 这位用户的默认偏好

用户最新指令优先，以下均可被当次要求覆盖。

| 项目 | 默认 |
| --- | --- |
| 资讯 | AIHOT 实时精选与热点为选题来源，覆盖其收录的全球 AI 文章、GitHub、论文、产品公告与讨论；外部原文用于核验 |
| 时间 | 北京时间 Asia/Shanghai；即时测试看滚动 24 小时，明示起止与采集时间 |
| 定时 | 每天 09:00 向当前任务推送简报，仅在实际创建/修改请求下操作调度 |
| 小红书 | 恰好五张独立竖图，第一张吸睛；无更适合参考时用蓝白极简科技杂志风 |
| 公众号 | 无更适合参考时用日照雪山、深色正文、章节色条与浅色结尾的杂志风 |
| 风格选择 | 两平台图库分别积累；用户指定参考优先，否则按主题、受众、信息量选最合适的图 |
| 内容 | 普通人能懂，数字带条件，不编造热度、实测或夸张结论 |

## 完整制作路线

1. 恢复当前项目、已选热点和最新参考。新成品放可写工作区，推荐 `ai-hot-content/YYYY-MM-DD/主题/`，不依赖某台机器的固定盘符，不覆盖无关旧稿。
2. 按 [资讯与事实](references/news.md) 抓取并核验；已选题则只更新有关证据。记录关键事实、来源、配置条件和未核实项。
3. 按 [参考图库](references/reference-library.md) 存新图或从对应平台历史图库选参考。记录选中条目与理由。
4. 先写清“发生什么、读者为何关心、结论有哪些条件”，再分别制作 [小红书五图配文](references/xiaohongshu.md) 和 [公众号标题与排版](references/wechat.md)。只读本次需要的参考文件。
5. 逐张打开导出图片，检查文字、数字、单位、图数与手机可读性。提示词不能替代已生成图片。完整套装提供真实文件和 ZIP；缺项如实列明。
6. 有发布或定时请求时按 [对应操作](references/publishing.md) 继续。平台回执/实际页面是保存或发布成功的依据。

## 交付组织

完整双平台包包含：`选题与来源.md`；小红书 `01.png` 至 `05.png`、`配文.md`、`配图提示词.json`；公众号 `标题与摘要.md`、`正文.md`、`排版预览.html`、封面和正文图；`交付状态.md`。

状态写清：未操作、已填入、已保存草稿、已发布或需用户处理；平台实际返回文章/草稿链接时再记录，并去除会话 token。部分请求只创建必要文件。

## 能力依赖

- 新闻发现必须调用当前已安装的 `aihot`，先读其最新指令并请求实时 API。缺失时按 AIHOT 官方安装说明补装；失败时按其重试规则处理并如实报告，不用其他新闻榜单填充为 AIHOT 日报。
- 生成/编辑位图用当前 `imagegen` Skill 和工具；编辑前查看原图。没有工具时先完成文字方案，明确缺少成图。
- 参考图归档用随附脚本，普通复制与哈希校验不改变图片像素。
- 平台操作用实际可用的连接器或浏览器工具；本地预览不等于公众号内排版。
- 定时用宿主自动化工具；Skill 文件本身不执行定时任务。

## Eagle 制图参考入口

制作图片时优先使用 [Eagle 参考图库](../../apps/eagle-reference-library/SKILL.md)，先同步并筛选 `<用户自己的Eagle图库>`，实际查看候选原图后再生成。按 [参考图库](references/reference-library.md) 的 Eagle 优先规则记录选择；用户当前明确指定的参考优先级最高。公众号成品默认交付一张完整长图。
