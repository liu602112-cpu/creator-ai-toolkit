# AI热点图文工作流

核对 AI 资讯来源，分别整理成小红书图文与公众号内容。

- 输入：AIHOT 实时资讯、选题和版式参考
- 输出：小红书五图配文、公众号稿和来源记录

## 使用

把本目录复制到支持 Skill 的工具的技能目录，然后用自然语言描述任务。使用说明在 [SKILL.md](SKILL.md)。

## 公开版范围

保留方法、脚本与模板。私人 CSV、完整逐字稿、账号凭据、克隆声音、原始课程和第三方媒体不随包发布。示例数据用于演示，不代表真实传播效果。

依赖 AIHOT 实时资讯入口 https://aihot.news 。需要先安装其官方 aihot Skill；配图及后台发布分别依赖可用的图像和浏览器工具。
