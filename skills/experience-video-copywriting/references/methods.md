# 方法与传播因子

本文件将江汤锅底 AI 编导案例中的叙事动作抽象为可选方法。它们解释内容怎样提供观看理由，不保证流量。原句和数据位置见 [来源案例](source-case.md)。

## 六种可迁移机制

### M1 先让观众知道为什么在意

原片以职业选择进入 AI 编导，随后追问作品、商单和学习门槛。对不懂 AI 的观众，工作与学习机会构成入口；对创作者，制作方法构成入口。

**可能作用：**让专业主题与观众的生活问题建立关系，扩大能理解内容的人群。

**怎么使用：**先找目标观众在什么场景面临什么问题，再说这项能力会带来什么具体改变。价值可以是理解、完成任务、节省步骤、避免错误或作出选择，不必是收入。

**适用条件：**这个改变与正文有关且有材料支撑。面向熟练用户时可直接进入细节，不必从大众职业话题绕行。

**失效写法：**只有“新风口、改变命运”，讲完仍不知道能解决什么；每个知识题都添加转行故事。

### M2 用真实差异提出一个值得求证的问题

原片将高赞作品与“一个人、一台电脑”放在一起，主持人说“我绝对不信”。意外的结果与实现条件形成待核实的差异。

**可能作用：**产生具体的信息缺口：如何做到、条件是否完整、是否适合我。

**怎么使用：**从真实材料中选择一组可比较的结果与条件，随后立即说明将怎样核实。可以是质量与资源、预期与实际、旧方法与新方法、看似简单与实际困难。

**适用条件：**两端比较口径一致。交代团队协助、已有经验或前期准备；只完成某个环节，就不写成独立完成全流程。

**失效写法：**编造成绩、故意隐藏决定性资源；用“居然、震惊”代替实际差异。

### M3 让追问推动求证

原片依次追问收益、是否原本会 AI、能否上手、什么人适合。主持人承担普通观众的提问角色。

**可能作用：**观众能沿疑虑理解信息；答案通过追问、行动和结果得到核实。

**怎么使用：**按实际疑虑选择问题：成果是谁完成的、条件是什么、哪里最难、怎样开始、如何判断做对、失败怎么办。每次追问推进一个新的判断，不重复“真的吗”。

**适用条件：**有真实互动或可展示的验证动作。单人口播可以用真实的原判断和验证过程，不编造采访对话。

**失效写法：**主持人持续捧场；专家说完无人追问；问了收益却始终没有可信回答。

### M4 用具体产物兑现方法

原片台词围绕选题、脚本、角色设定、分镜、素材和成片推进。教程入口附近出现点赞人数局部高点；评论追问所用工具。

**可能作用：**使机会变成可以理解的路线，提供保存和尝试的理由。

**怎么使用：**每个主要步骤交代“输入—关键操作或判断—产物—下一步怎么用”。镜头允许时让观众看到产物变化，旁白解释选择理由。

**适用条件：**教程目标明确。完整教程交代工具入口、重要成本和关键难点；体验记录可以简化操作，但不要宣称已教会所有人。

**失效写法：**只报步骤名称；在最难环节跳过；展示成片，却没有说明其与前面步骤的关系。

### M5 展示判断与纠错

原片讨论剧本可以更“痛”，又担心“刻意”，并提到多轮修改。过程包含创作判断。

**可能作用：**让观众理解专业能力怎样发挥作用，同时给体验增加真实变化。

**怎么使用：**保留最能解释结果的一次失败或取舍：“这版哪里不对—为什么—改哪一点—改后有什么变化”。无需把所有试错都放进视频。

**适用条件：**实际发生且能讲清原因。只有顺利完成的材料，可以展示选择标准，无须制造失败。

**失效写法：**虚构翻车；将成功完全归给工具；把专业人士的判断省成“调一调就好了”。

### M6 用真实发现扩展主线

原片揭示女孩的管理身份，结尾讨论 AI 情绪呈现及未来影响。评论中同时存在人物认出、学习咨询和科技讨论。

**可能作用：**给不同观众提供额外关注点，让体验产生人物或认识层面的变化。

**怎么使用：**有真实身份发现时，呈现观众尚不知道、又与能力有关的一面；有体验后的认识变化时，回到原判断，说明什么证据改变了它。

**适用条件：**新信息与主线有关。有观点就交代支持范围；疑问可以保留为疑问。没有人物反差或更大议题时，用实际结果与适用条件结束即可。

**失效写法：**每个人都写成隐藏大佬；结尾突然转宏大问题；把表现某种情绪的效果写成证明意识或理解。

## 按需要改善的观看行为选方法

| 当前问题 | 优先考虑 | 需要观察什么 |
|---|---|---|
| 主题专业，观众不知道为什么看 | M1、M2 | 观众能否复述具体问题；开头是否进入承诺 |
| 介绍像推销，观众疑虑没被回应 | M3、M5 | 对关键条件的追问是否获得证据 |
| 听起来有用，但无法开始做 | M4 | 工具入口、产物、关键条件是否齐全 |
| 过程平，只有顺序没有变化 | M5 | 是否有真实选择、阻力和修正 |
| 故事结束却没有清楚结论 | 结果回答主问题；有材料再用 M6 | 结论是否由体验支持 |

收藏可能来自方法价值，分享可能来自帮助朋友、作品认出或话题讨论；不能只凭动作数量确定动机。需要结合真实评论、调查或更明确的数据验证。

## 拆解与复盘口径

先写观察，再写解释，再写下一次可检验的改法。例如：“01:12 的点赞人数形成局部高点，附近开始教学；一种解释是观众期待具体方法。下一次比较不同教学入口，观察留存和具体学习反馈。”不能改成“开始教学让播放翻倍”。

遇到数据时先确认视频对象、采集时间、统计窗口、单位和分母：

- 点赞／播放、分享／播放与收藏／播放可作为对应口径下的近似比值；人数不是率。
- 0 秒端点、点赞人数和未经解释的流失字段，不能直接还原留存或完播。
- 两份评论快照先按作者与规范化文本去重，后一次抓取优先保留；没有评论 ID 时不声称精确唯一人数。
- 排序后的部分评论不是随机样本；评论中的成本、产品能力与推荐话术属于用户说法，未经核验不升级为事实。
- 没有账号基线、粉丝量、流量来源或可比作品，不断言“超行业平均”“纯自然流量”或某因子的推荐权重。

默认挑最有材料支撑的因子。每项包含具体内容动作、可能影响、依据和适用条件；不用任意分数装饰判断。
