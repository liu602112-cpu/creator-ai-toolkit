# 选题发现和筛选

这是对用户方法论文档与案例的应用改编。源头对应见 [source-map.md](source-map.md)；下面的优先级和取舍属于编辑设计。

## 从哪里找题

| 信号 | 转成选题的办法 | 缺口与限制 |
|---|---|---|
| 自己正在做的事 | 把工作流程拆成节点，记录每一步的选择、失败、修正和成果 | 有过程才能说亲历；没做过可规划实测，不先写结果 |
| 评论、咨询和访谈 | 保留用户原问题，找具体对象、场景和阻碍；相同困惑合并 | “评论数多”不等于已知评论内容；身份不可从一句话确定 |
| 搜索需求 | 保存原搜索词，转成人群+场景+问题 | 联想词是线索，不能直接推定搜索量或供需缺口 |
| 自己或同类历史内容 | 找重复问题与表现异常，分离题材、包装、结构、人物和时机 | 高互动只说明样本数字；需控制账号、时间、形式等差异 |
| 阅读与研究 | 把新理解落到观众熟悉的现象，用例子或演示解释 | 学到的新知识不一定是观众需求；原论断需要合适证据 |
| 当前事件与季节 | 找与核心观众和专业的实际连接 | 核验日期与现状；时效窗口未知就不编截止日期 |

缺少外部或自身需求信号时，允许提出假设题，附一个便宜的验证动作，例如对照用户的最近咨询、检索具体问题的近期讨论、先问目标用户遇到了什么。不要把“做个投票/发出去看看”说成已经验证。

## 把主题变成能讲的题

用一句话描述：“给[某类人]在[某个情境]回答[具体问题]，用[自己有的材料/方法]让他获得[明确结果或判断]。”这个句式用于思考，不要求输出机械填空。

例如“学AI”过宽。若用户实际材料是一段自己整理会议纪要的流程，可缩成“会议录音转文字后，怎样检查AI有没有漏掉决策和责任人”。没有该流程时，这只是示例方向，不是用户已经能讲的亲历。

用XY检查切口：X是主题，Y是真正值得讲的细节。“视频素材管理”是X，“按成品分类存了很多，写稿时仍然找不到一个可用镜头”可以是Y；“很有用/很重要”不是Y。遇到纯教程无需强行找冲突。

聚类按问题和承诺，不只按关键词：把“为什么剪辑这么慢”和“怎么做文件备份”都放进“剪辑”会掩盖不同需求；把“存了很多却找不到素材”和“素材库搜不到可用片段”当两题又可能重复。

## 拆参考作品

按可见材料填写，缺项留未知：

人群 → 情境 → 核心问题 → 用户期待 → 角度 → 核心回答 → 证据 → 表达形式 → 时效 → 内容目标。

另写两句：“哪些结构能借鉴”“哪些东西依赖原作者，不能搬”。只有标题时不补正文；有转写时保留转写不确定性；原观点未核实就不当作科学结论。

对表现的解释使用“可能与……有关，需……”的方式。需要判断反复出现的题时，查独立作品与不同时间证据，排除同题重复发布、广告/自然内容混样、采样选择偏差。资料不足就描述样本，不认定因果。

## 先过立项门槛

按当前账号和投入判断：

- 目标观众是否会遇到或在意这个问题？没依据则先是需求假设。
- 用户有没有可支撑核心回答的经验、数据、资料或演示？没有就补材料或缩小承诺。
- 是否符合用户的领域、表达习惯和本轮目标？高热度不能替代匹配。
- 能否用现有条件完成？若必须等实验、访问、客户授权或昂贵拍摄，不能进“今天可做”。
- 是否存在核心事实错误或不必要的夸大？修正后再排顺序。

“低成本、值得试”可以是合理建议，但仍需说明未验证部分；“材料齐”不自动证明需求强。

## 怎样增加差异

优先找观众仍无法行动或判断的地方，而非只换标题词：

| 已有内容 | 可新增的价值 |
|---|---|
| 讲一般人 | 明确一个未照顾到的情境或阶段 |
| 给结论 | 解释判断过程与适用条件 |
| 讲理论 | 用自己能做的演示展示步骤 |
| 列工具 | 给选择标准、对照实例和失败情形 |
| 只讲成功 | 分析真实失败、代价和修正 |
| 说“因人而异” | 说明究竟按哪个可观察因素选择 |

本地样本中没有一个题，只能说“本库未见/样本未覆盖”，不能说“市场没人做”或“蓝海”。有供需数据时再讨论高需求低供给；只有搜索联想、零散评论时讨论“缺口假设”。

## 优先级与可选评分

默认给状态和决定性理由：

- **建议先做**：受众关联、内容回答和证据路径清楚；若需求仍需验证，明说这是低成本试拍。
- **补资料后做**：有价值线索，但关键数据、案例、实际操作或权限尚缺；写明缺哪一项。
- **待验证灵感**：尚无足够需求依据或账号信息，先小范围验证。
- **暂缓**：偏离用户目标、无法提供实质内容、成本不合算，或依赖不成立的核心承诺。

用户明确要数字评分时，可使用母文档D640–D650的**实验参数**：需求25%、历史验证20%、缺口15%、创作者优势15%、价值10%、分享动机5%、时机5%、可执行性5%。不是平台公式，不是20份来源共同结论。

每维用0–3的粗档判断并给一句依据，未知记“未知”而非0。资料不全默认不算总分；确需部分汇总时同时显示已覆盖权重和未知项，只比较同样信息覆盖的题，避免伪精确。证据缺口与立项门槛优先于总分，不给“成功概率”。没有时间窗口的常青题不因“非热点”天然扣分。权重调整只能作为建议，经用户选择后用于后续工作。

## 系列与选题组合

参考自己的流程、观众阶段或决策路径形成系列，每集独立解决一个问题。例如素材库系列可分为“为何存了却用不上 → 怎么拆成可用片段 → 怎么检索 → 怎样绑定来源 → 一周后怎样淘汰无用分类”。这些是编辑示例，是否拍取决于用户实际经验。

别为了五集把同一个结论拆成五个标题。必需先掌握的概念排前面，能立即演示的题优先；素材尚缺的题先安排补采。时效题以本轮核实的窗口排序，常青题按用户成本与目标排序。

常规题、时效题、系列题承担不同任务；不规定固定比例。用户要涨粉、信任、咨询或转化时，相应调整选题目标。没有产品或需求验证时，不推断“这些题肯定赚钱”。
