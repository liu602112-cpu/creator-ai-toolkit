# 用户默认知识科普视频结构与形式

2026-10-06，用户明确要求：以后给选题、要求口播文案和提示词脚本时，未另行说明就沿用本次结构与风格。这份约定用于知识科普视频，尤其健身讲解；不把它强加到朋友圈、广告短句或其它纯文字任务。当前明确要求始终优先。

## 默认交付

给两份可用内容：口播稿和配套制作提示词脚本。已建立的交付形式为两份Word；环境支持时保存并通过文档渲染检查。不要只输出提纲或制作建议。用户只要求其中一份时按其范围。

口播正文不超过1400个非空白字符，包含标点、数字和拉丁字符；研究依据、镜头标签及制作说明不计入口播正文，也不念。标清A-roll与B-roll的具体句子，附短镜头提示；不能只在整篇顶部标一种镜头。两份文件使用同一版完整正文，提示词末尾锁定口播全文。

## 讲解方式

参考用户的“帅soserious”逐字稿：从具体处境或目标进入，研究给出信息，用直观解释、对比或准确类比讲清含义，再落到实际安排。自然中文口语，短句推进；不堆金句、不铺宏大背景、不虚构作者亲历，不复制参考中的补剂剂量、广告或效果承诺。

保留这条内容链：实际问题 → 有边界的核心回答 → 关键研究 → 为什么及适用条件 → 如何实践 → 具体记录或判断 → 回到开头问题。需要时先解释术语；段落、文献与镜头数量按内容决定，不强制每篇恰好15段或7次出镜。

## 画面采用混合形式

- **A-roll**：用户本人对镜头讲述，主要承接问题、术语/关键解释、转折与结尾。本人只做动作而不对镜头讲这句时，仍算辅助B-roll。
- **实拍B-roll**：用动作、身体局部、器械、物体、手机和记录，让观众看清当前句子说的事。有真实可用素材就优先用有关素材，不机械凑固定实拍比例。
- **人物动画B-roll**：实拍不足或需要展示不可见关系时，可以用人物动画替代。保持同一角色、器械、动作方向和配色；接触点、轨迹、遮挡及3D空间关系正确。动画示意不是实验实录或实时生理读数。
- **文献与图解**：真实来源和当前论断对应；可叠在实拍/动画背景上。用人物/动作带解释，不退回通用卡片或随机健身空镜。

每段B-roll提供首选实拍与人物动画替代方案，注明何时采用；不要把缺素材当成必须先批准或必须放弃的理由。没有素材时仍可以完成稿件、动画方案、工程准备和补拍清单，但不能声称已拍摄或已验证成片。

## 文献与提示词结构

按“真实出处 → 对应证据局部 → 中文重点 → 回到行为/动画应用”组织。出处与高亮按口播逐步进入，一次强调一个位置，停稳可读。原图、重绘和概念示意分清；无真实数据就不造坐标、百分比、肌肉增长量或论文截图。

提示词沿用这些模块：项目目标、成片规格/素材入口、科学边界、视觉组织、工程与配音同步、逐段分镜、文献规范/证据交接、字幕层级、声音节奏、研究依据、可直接复制的执行指令与锁定正文。模块可合并，不能漏关键执行信息。

证据交接固定六栏：口播论断、原始来源、原图/原句定位、观众要看的位置、中文解释、接回哪个实拍或人物动画。对应分镜至少包括口播锚点、A/B类型、首选实拍、动画替代、文字/图解与边界。

默认竖屏1080×1920、30fps；具体时长和时间码由最终配音/SRT决定，不编造已同步的字幕。字幕与最新正式项目配置相符，A/B镜头分配不自动改变字幕。科研结果保留样本、方案和测量范围，建议与研究发现区分；健康事实每期查可信来源。

写口播和提示词不自动授权制作或发布视频。用户后续要求制作时按实际素材完成可观看预览及必要QA，当前版本批准后再原生高清导出。
