# 结构与内容选择

素材决定结构。下表按用户DOCX第九部分整理，属于写作工具，不是必须完整逐项执行的模板。短稿保留有效环节，长稿可分章节；信息不够的环节不能用虚构补齐。

| 类型 | 推进顺序 | 素材门槛与检查 |
|---|---|---|
| 问题解释 | 具体问题 → 结论 → 原因/机制 → 证据或例子 → 怎么做 → 边界 | 结论有依据，机制与类比不混同 |
| 反误区 | 常见说法 → 合理之处 → 出错位置 → 更准确解释 → 做法 | 常见说法确实存在；没有证据不写“所有人错了” |
| 方法教程 | 场景 → 常见错误 → 判断标准 → 步骤 → 示例 → 注意事项 | 读者知道什么时候用、怎样做对；步骤数量由任务决定 |
| 对比决策 | 选择场景 → 同一维度比较 → 各自适合谁 → 决策规则 | 比较依据和条件一致，不把一种永远写成更好 |
| 案例复盘 | 原状态 → 问题 → 发现 → 处理 → 实际变化 → 可迁移原则 | 有真实动作与结果；相关性不直接等于因果 |
| 故事 | 人物目标 → 阻碍 → 选择/行动 → 转折 → 结果 → 反思 | 每个转折有前因；真实故事不得补造对话和结果 |
| 观点论证 | 议题/常见看法 → 我的判断 → 理由和证据 → 反例/边界 → 结论 | 区分观点与事实，不靠编造“专家认为”证明 |
| 实验验证 | 问题 → 假设 → 如何测试 → 过程 → 结果 → 解释 → 限制 | 只有实际做过且有材料才写实验结果，计划不能写成已完成 |
| 清单诊断 | 当前问题 → 可观察信号 → 各信号含义 → 优先动作 | 不把一般自查冒充专业诊断；避免孤立症状决定结论 |
| 热点延展 | 已核验事件 → 与受众的关联 → 解释 → 影响 → 行动 | 查当前来源，不根据历史表格虚构“今天热榜” |
| 评论回复 | 真实问题 → 结论 → 原因 → 可用方案 → 例外 | 没有原评论时标为常见/假设问题，不假冒粉丝原话 |
| 转化 | 用户问题 → 当前办法的不足 → 方案 → 机制 → 证明 → 疑虑/适用对象 → CTA | 功能、证明、成交条件来自真实材料；价值不靠造焦虑 |

故事和案例可以用50字左右的内部摘要检查“谁、想要什么、被什么卡住、做了什么、发生了什么变化、为什么在意”。不能概括时先收窄，不强行三幕剧。资料缺结果时可写事件进展或观点，不默认制造逆袭结局。

## 标题和开头

先选真实诉求再写句子，区分标题吸引阅读和首句进入正文。一个核心主张可以用不同进入方式，但事实范围相同。

| 信息作用 | 怎样写 | 兑现要求 |
|---|---|---|
| 命中处境 | 点出具体人群正在遇到的麻烦 | 正文解决这个麻烦 |
| 利益/结果 | 给出能得到的知识、判断或实际价值 | 收益清楚，有条件的不说绝对 |
| 真实风险 | 描述忽视问题的具体代价 | 风险有材料依据，不恐吓 |
| 新信息 | 呈现有依据的新发现或更新 | 能说明新在哪里和依据 |
| 冲突 | 同时出现“想要什么”和“被什么卡住” | 方案回应两端，不换题 |
| 悬念/现场 | 给关键事件或暂缺一块信息 | 很快补实质答案，不无限吊胃口 |

不给每篇强制反常识或问题句。已经选定角度时，标题的区别可以来自对象、利益或解释入口，不必改动核心结论。用户要多个版本时确保差异实质存在。

## 渠道与形式

下列是表达选择，并非平台算法、官方规则或“最佳字数”。具体长度、标题限制和平台政策有时效性，必要时另查当前规则。

- **短视频口播**：为听觉安排信息顺序，删阅读式铺垫；关键原因由语言解释，能通过演示证明的内容给画面。用户只要口播时不自动变成分镜表。
- **小红书/社交图文**：用可扫读的段落和具体场景提供帮助，清楚写适用对象；标签、图片页数按用户要求，不套五图发布流程。
- **公众号/长文**：展开必要背景、依据和因果，小标题服务阅读；信息不靠换同义词拉长。用户只要文本时不自动做长图或文档。
- **朋友圈/私域**：根据真实关系和目的写，保留个人声音，CTA符合现有产品及沟通渠道；不假装熟悉用户或伪造晒成绩。
- **广告/产品文案**：受众认知决定解释深度；把功能连到具体情境利益，回应关键疑虑，明确下一步得到什么。
- **品牌短句/口号**：围绕一项已确定的信息和品牌声音反复打磨；不靠陌生术语装深刻，不宣称未经证明的第一、唯一。

## 口播和画面的互补

完整视听脚本需要时，将信息分为必须说、最好看、可字幕。旁白负责看不见的原因和判断；画面呈现动作、关系、变化和证据。没有现成素材时写“建议拍摄/待素材”，不能声称用户已经有视频、实验或结果截图。

避免画面与口播重复报同一个可见动作，但关键步骤、安全条件或理解所必需的内容可同时用声音和字幕强调。分工是为了理解，不是机械禁止重复。
