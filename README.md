## 网站与软件

- **[DropKit Windows](https://liu602112-cpu.github.io/creator-ai-toolkit/projects/dropkit-windows/)**：把剪贴板内容和文件临时收在一个浮窗里，支持搜索、固定与拖拽取用。 [源码](https://github.com/liu602112-cpu/creator-ai-toolkit/tree/main/apps/dropkit-windows)
- **[每日热量消耗计算器](https://liu602112-cpu.github.io/creator-ai-toolkit/projects/daily-energy-calculator/)**：输入身体信息和日常活动情况，估算基础代谢与每日热量消耗。 [源码](https://github.com/liu602112-cpu/creator-ai-toolkit/tree/main/apps/daily-energy-calculator)
- **[视频复盘网站](https://liu602112-cpu.github.io/creator-ai-toolkit/projects/video-retrospective/)**：把视频制作中的问题、处理方法和下次动作整理成可搜索的复盘档案。 [源码](https://github.com/liu602112-cpu/creator-ai-toolkit/tree/main/apps/video-retrospective)
- **[IP操盘手知识库网站](https://liu602112-cpu.github.io/creator-ai-toolkit/projects/ip-operator-knowledge-base/)**：按定位、选题、访谈、制作和复盘检索知识，快速找到可执行的方法卡。 [源码](https://github.com/liu602112-cpu/creator-ai-toolkit/tree/main/apps/ip-operator-knowledge-base)
- **[Eagle视觉参考检索库](https://liu602112-cpu.github.io/creator-ai-toolkit/projects/eagle-reference-library/)**：给 Eagle 图库建立本地索引，按分类、标签和配色寻找视觉参考。 [源码](https://github.com/liu602112-cpu/creator-ai-toolkit/tree/main/apps/eagle-reference-library)

## Skills

- **[视频选题编辑](skills/content-topic-planner)**：把账号方向、观众问题和现有素材整理成值得拍的具体选题。
- **[短视频开头教练](skills/video-opening-coach)**：围绕视频看点设计自然的开头，并衔接首镜头与正文。
- **[通用文案教练](skills/copywriting-coach)**：把真实资料写成清楚、自然、能直接念的中文文案。
- **[体验故事文案](skills/experience-video-copywriting)**：把工具实测和职业体验写成有任务、有尝试、有验证的故事。
- **[AI热点图文工作流](skills/ai-hot-publisher)**：核对 AI 资讯来源，分别整理成小红书图文与公众号内容。
- **[健身热点图文工作流](skills/fitness-hot-publisher)**：从健身热点发现问题，再用官方资料或研究核验，制作平台内容。
- **[vibe视频制作](skills/vibe-video)**：把真实素材、解释动画和音乐安排成连贯的视频制作方案。
- **[声音与数字人口播](skills/hifly-avatar-video)**：使用获授权的配音与形象视频，组织音频驱动的数字人口播制作。
- **[剪映草稿读取与修改](skills/jianying-draft)**：读取剪映草稿的轨道、字幕和素材，导出逐字稿并在副本中修改。
- **[直播访谈口播切片](skills/live-clip)**：从直播或访谈中选出完整观点，精剪停顿、整理字幕并做画面包装。
